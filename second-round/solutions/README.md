# 二面笔试题参考答案

本目录包含所有笔试题的参考答案和详细讲解，**仅供面试官使用**。

## 目录结构

```
solutions/
├── flatten/           # 数组扁平化参考答案
│   ├── README.md      # 详细实现指南
│   ├── flatten-recursive.js   # 递归实现
│   ├── flatten-iterative.js   # 迭代+栈实现
│   ├── flatten-reduce.js      # reduce 实现
│   ├── flatten-depth.js       # 支持深度参数
│   └── test.js                # 测试套件
│
└── react-pagination/  # React 分页参考答案
    ├── README.md      # 详细讲解
    ├── App-basic.tsx  # 基础实现
    ├── App-advanced.tsx   # 进阶实现
    └── usePagination.ts   # 自定义 Hook
```

## 使用说明

1. **发送题目给应聘者时**：只发送 `writing-questions/` 目录
2. **评分参考**：参考本目录的实现和评分标准
3. **面试讨论**：根据应聘者的实现，参考 README 中的考察点进行提问

## 注意事项

⚠️ **请勿将本目录内容发送给应聘者**
